# Dynamsoft Capture Vision Server SDKs

Dynamsoft Capture Vision server-side SDKs enable barcode reading, label recognition, document normalization, and code parsing in server and desktop applications.

## Available Editions

| Edition | Description |
|:--------|:------------|
| [C++ Edition](programming/cplusplus/) | For C++ applications on Windows and Linux. |
| [.NET Edition](programming/dotnet/) | For .NET applications using C# or VB.NET. |
| [Java Edition](programming/java/) | For Java applications on any platform with JVM support. |
| [Python Edition](programming/python/) | For Python applications and scripts. |
